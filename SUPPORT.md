# Support

Logosphere is pre-1.0 and maintained by one person. There is no guaranteed
support or response-time agreement.

## Supported surfaces

- Full graphical engine: macOS on Apple Silicon.
- Headless physics profile: Linux and macOS with a C++17 toolchain.
- Headless core profile: Linux and macOS with a C++17 toolchain.
- Windows: not currently verified or supported.

Support applies to the latest tagged release and current `main`. API
compatibility may break between pre-1.0 minor releases when documented in
the changelog.

## Where to ask

Use the GitHub issue tracker for reproducible defects. Include the Logosphere
version or commit, build profile, operating system, compiler, exact command,
complete error, and a minimal reproduction.

Use GitHub Discussions for design questions and general usage only when
Discussions is enabled on the repository. Do not use the security contact
address for ordinary support.

Feature requests should describe the concrete game or engine use case. A
proposal that belongs to one game rather than the generic engine may be
declined or redirected to a game layer.

## Out of scope

The project does not provide support for private forks, modified build
systems, unreproducible local environments, third-party game code, or
platforms outside the supported matrix. Commercial support terms, if any,
will be documented separately from the source license.
